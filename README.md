# NJU AIA AI News

Production deployment for `news.nju-aia.com`.

- All candidates are ingested; no daily hard cap.
- Homepage shows only 3 items per selected topic.
- Daily timer: 08:15 Asia/Shanghai.
- Discourse publishing is intentionally not enabled until a bot/API key exists.

## Repository contents

This repository tracks the active application source, public source configuration, deployment unit templates, and editorial policy used by the production service. Runtime state, local agent state, backups, credentials, and editorial batch working data are intentionally excluded.
